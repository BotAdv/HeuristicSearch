# 组合猜序列 · 启发式搜索沙盒 — 文档索引

> 本项目用于在**可复现的沙盒环境**中对比不同启发式搜索策略在“组合猜序列”游戏里的表现。
>
> **当前规则**：候选组合 45 个、序列长度 10、**秘密序列的 10 个组合两两互不相同**、
> 逐位反馈优先级 `CORRECT > MISPLACED > PARTIAL > WRONG`。
> 本文档目录按**功能与任务类型**分文件记录；新功能新建文件，功能修改记录在对应说明文件中。

## 一句话结论（详见 06）

* **当前（秘密组合互异）规则下，“先定支持集、再定顺序”的两阶段策略反而是最优的**：
  平均 **6.13 轮**（默认配置，200 局）；把 `lock_known_positions` 关掉可再降到 **5.77 轮**，
  其余有效策略在 6.26–7.05 轮之间。
* 原因：互异规则直接给出“重数恒为 1”，于是**常数序列探针彻底失去意义**，
  两阶段的分阶段成本降到最低；同时“已安置组合⇒全局删除”成为最强剪枝。
* 旧规则（允许重复）下结论完全相反：两阶段 12.785 轮（最差），
  逐位置贪心 6.460 轮（最优）。**任一个策略排名都必须连规则一起报出。**
* `global_prune`（`P`/`W` ⇒ 组合不在支持集 ⇒ 从所有位置删除）的价值从旧规则的 −2.35 轮
  降到新规则的 −0.30 轮，因为它把主导地位让给了“已安置值全局传播”。
* 粒子滤波 + 全局最大熵依旧最弱且最贵（7.05 轮 / 75 ms，是两阶段的 80 倍），
  粒子数 32→512 收益为零、耗时线性增长。
