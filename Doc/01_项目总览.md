# 01 项目总览

## 1. 项目目标

搭建一个**可扩展的 Flask + 前端沙盒**，用来验证“组合猜序列”游戏上不同启发式搜索策略的性能。

需要验证的四个核心问题：

1. 不同启发式策略在**期望步数**上的表现差异；
2. 是否存在比“先确定组合集合，再确定顺序”更优的**混合策略**；
3. “正确但位置错误”（MISPLACED）反馈对**最坏/期望步数**的影响；
4. **动态自适应**策略与**固定策略**、**贪心策略**的对比。

## 2. 三层架构

```
┌──────────────────────────────────────────────┐
│  core/        纯规则层（无策略、无 IO）        │
│  game.py        组合空间 / 反馈判定 / 校验     │
│  sequence_game.py  单局状态机                 │
│  journal.py     把对局与模拟写进 Doc/          │
└──────────────────────────────────────────────┘
                    ▲
┌──────────────────────────────────────────────┐
│  strategies/  策略层（可插拔）                 │
│  base.py        策略接口 + 参数声明            │
│  belief.py      共享信念工具（逐位置集合/支持集）│
│  5 个具体策略                                  │
└──────────────────────────────────────────────┘
                    ▲
┌──────────────────────────────────────────────┐
│  engine/      实验层                          │
│  simulator.py   配对批量模拟                  │
│  metrics.py     指标 + 符号检验               │
│  jobs.py        后台任务/进度/取消             │
└──────────────────────────────────────────────┘
                    ▲
┌──────────────────────────────────────────────┐
│  web/ + templates/ + static/   展示层         │
│  /            沙盒（手动 + 策略自动）          │
│  /strategies  策略库                          │
│  /lab         模拟实验台（表格 + 图表 + 导出）  │
└──────────────────────────────────────────────┘
```

**为什么这样分层**：规则层不依赖任何策略，保证所有策略面对完全相同的判定标准；
策略层只通过 `history` 观察游戏，拿不到秘密序列，杜绝“偷看答案”导致的虚假性能。

## 4. 快速上手

```powershell
conda activate flask_env
cd E:\Project\Interest\HeuristicSearch

python app.py                      # 打开 http://127.0.0.1:5000
python -m unittest discover -s tests
python experiments/benchmark.py --games 200 --max-rounds 60
python experiments/benchmark.py --preset two_phase_vs_hybrid
python experiments/benchmark.py --plan "position_entropy:pick_mode=split,position_entropy:pick_mode=entropy"
python experiments/benchmark.py --all-presets
```

环境变量（都可选）：

| 变量 | 默认 | 用途 |
| --- | --- | --- |
| `HS_PORT` | 5000 | 端口 |
| `HS_DEBUG` | 0 | 调试模式 |
| `HS_MAX_GAMES` | 5000 | 单次模拟最大局数 |
| `HS_MAX_ROUNDS` | 120 | 默认轮次上限 |
| `HS_MAX_JOBS` | 2 | 同时运行的后台任务数 |
| `HS_DOC_LOG` | 1 | 是否把对局/模拟写入 `Doc/` |
| `HS_DOC_LOG_ROUNDS` | 1 | 是否记录**每一轮**明细 |

## 5. 扩展点

| 想做的事 | 改哪里 |
| --- | --- |
| 加新策略 | 新建 `strategies/xxx.py`，加入 `strategies/__init__.py` 的 `CLASSES`（前端自动出现） |
| 改规则（例如换掉被删除的 10 个组合、改序列长度） | `core/game.py` 顶部常量 |
| 加新指标 | `engine/metrics.py: summarize()` |
| 加新实验预设 | `web/api.py: api_presets()` 与 `experiments/benchmark.py: PRESETS` |
| 加新页面 | `web/pages.py` + `templates/` |
