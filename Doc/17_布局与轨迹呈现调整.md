# 17 · 布局与轨迹呈现调整（1.8.0）

> 这一轮把「拥挤」和「该藏起来的东西没藏住」一起处理掉：参数栏真隐藏、每张卡片铺满可用宽度、
> 公共按钮上提到面板顶部、逐步猜测页降为两列、策略库的试玩轨迹直接长在卡片右侧。
> 相关文件：`templates/index.html`、`templates/human.html`、`templates/strategies.html`、
> `static/js/strategies.js`、`static/css/app.css`。

## 1. 参数栏没有真的被隐藏（最重要的一个 bug）

**现象**：手动试玩页签的顶部提示写着「参数与开关已收起（…）／显示参数栏（F9）」，
但下面的种子、轮次上限、策略等输入框**照样显示**。

**根因**：`hidden` 属性在浏览器里只是 UA 样式表的一条规则：

```css
/* 浏览器内置（UA 样式表） */
[hidden] { display: none; }
```

而作者样式表里的 `.toolbar { display: flex; }` 优先级**高于 UA 样式表**（与选择器权重无关，
作者样式表整体胜过 UA 样式表），于是 `el.hidden = true` 只改了属性、元素依旧按 `flex` 排版。

**修法**（`app.css` 顶部，全局兜底）：

```css
[hidden] { display: none !important; }
```

**验证**（1440px 视口，浏览器实测）：

| 状态 | `getComputedStyle(toolbar).display` | 高度 |
| --- | --- | --- |
| 默认（收起） | `none` | 0 px |
| 按 F9 | `flex` | 77 px |
| 再按 F9 | `none` | 0 px |

> **教训**：自查「东西藏起来了吗」必须看**计算样式或几何尺寸**（`display` / `height`），
> 只看 `el.hidden === true` 会漏掉这类"属性生效但视觉没变"的 bug。
> 本项目再无第二个元素同时具备「有 `hidden` 切换」与「类上有 `display`」，但这条规则让以后也不会踩。

## 2. 单策略页签：两张卡片两列铺满

手动试玩 / 策略自动各只有两张卡片（候选组合矩阵 + 历史序列），三列模板会在右侧留一条空位。

```css
/* 旧：3 列 */
.sandbox { grid-template-columns: minmax(360px,1.1fr) minmax(300px,1fr) minmax(320px,1.1fr); }
/* 新：2 列（≤1080px 退化为单列） */
.sandbox { grid-template-columns: minmax(0, 1.05fr) minmax(0, 1fr); }
@media (max-width: 1080px) { .sandbox { grid-template-columns: 1fr; } }
```

* 实测 1440px：两列 710 / 676 px，第二张卡片右边缘 = 容器右边缘 → **右侧无预留空位**。
* 「决策解释」卡片初始 `hidden`（现在真的不占格）→ 出现时自动落到第二行，不会挤压上面两张。

## 3. 多策略对比：公共操作条

三个公共按钮（**开新局 / 所有策略各走一步 / 自动跑完**）从顶部工具栏搬到**三个面板正上方的公共条**，
与对局状态行同一行：左侧状态、右侧按钮。

```html
<div class="bar-common">
  <div id="multi-status" class="status">对局 multi-… · 共 3 个策略 | two_phase：6 轮 ✅ · …</div>
  <div class="bar-actions">
    <button id="multi-btnNew" class="primary">开新局</button>
    <button id="multi-btnStep">所有策略各走一步</button>
    <button id="multi-btnPlay">自动跑完</button>
  </div>
</div>
<main class="multi-grid" data-role="cards"></main>
```

* 工具栏里只剩参数（种子 / 轮次上限 / 显示秘密）与「参与对比的策略」面板。
* `.bar-common .status { padding:0; border:0; background:none; flex:1 1 320px; }`：
  状态文字沿用 `setStatus()`，但不再是独立的一条横幅。
* 实测：工具栏内按钮 0 个、公共条内 3 个，公共条整体位于卡片区之上；按钮功能不变。

## 4. 逐步猜测页：每行 2 列 + 对局历史下移

```css
.human { grid-template-columns: repeat(2, minmax(0, 1fr)); }   /* 旧：3 列 */
@media (max-width: 1080px) { .human { grid-template-columns: 1fr; } }
```

面板 DOM 顺序不变（本轮猜测 → 候选矩阵 → 对局历史 → 决策解释 → 已落盘对局），
两列布局下自动变成：

```
┌───────────────┬───────────────┐
│ 本轮猜测      │ 候选组合矩阵  │
├───────────────┼───────────────┤
│ 对局历史      │ 决策解释      │   ← 对局历史落在本轮猜测「正下方」
├───────────────┼───────────────┤
│ 已落盘对局    │               │
└───────────────┴───────────────┘
```

* 实测 1440px：两列各 685px；对局历史的 `left` 与本轮猜测相同、`top` 更大 ✓；
  一轮历史（10 个格子）在 656px 宽下仍是**单行**（高 38px），不换行。
* 顺手删掉 `panel wide` —— CSS 里从来没有 `.wide` 规则，属于历史遗留。

## 5. 策略库：轨迹长在卡片右侧

### 结构

```
.card                                   （默认：单列，flex 纵向）
├── .card-main    标题 / 标签 / 说明 / 参数 / [快速试玩]
└── .card-trace   [轨迹表头 + 收起轨迹] + 每轮猜测与反馈   ← 默认 hidden

.card.expanded                          （试玩后）
├── grid-column: span 2                 ← 跨两列，其它卡片自动顺延
└── grid-template-columns: 参数 | 轨迹   ← 轨迹出现在卡片「右侧」
```

* 轨迹表头：`对局轨迹 · 策略 X · 秘密 … · ✅ N 轮解出 · 0.00x 秒` + 「收起轨迹」按钮（单张折叠）。
* ≤1280px 时 `.card.expanded` 退回单列（`grid-column: span 1`），避免窄屏横向溢出。

### 顶部按钮

| 按钮 | 行为 |
| --- | --- |
| **跑一局** | **所有卡片**用各自面板上的参数各跑一局，全部展开轨迹；状态行汇总「策略：N 轮 ✅」 |
| **隐藏轨迹** | 全部收起（状态行提示「已隐藏全部 N 条对局轨迹」） |
| （每张卡片）快速试玩 | 只跑这一张，只展开这一张 |

* **取消**了顶部的「试玩策略」下拉框 `#qpStrategy`：想单独试某个策略就点它卡片上的按钮，
  想一次全跑就点「跑一局」。
* 底部公共的 `#tracePanel` 删除 —— 轨迹不再集中展示。
* 实测 1440px：卡片初始 452px；单张试玩后 918px 且 `trace.left - main.right = 14px`（正好一个 gap）；
  跑一局后 5 张全部 918px 且各自 6–7 轮；隐藏轨迹后全部回到 452px。

## 7. 自查脚本里的两个坑

* 别用缓存的 DOM 节点连续点击：`place()`/`renderCards()` 会重建节点，**每次重新查询**。
* 汇总时别想当然认为返回体里有策略中文名：`/api/quickplay` 只返回 `strategy`（key），
  中文名要从前端策略表里取，否则状态行会打印 `undefined：7 轮 ✅`。
